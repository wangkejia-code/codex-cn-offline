# Codex 中文离线工具

这个工具解决的是 Codex 侧边栏（左侧导航、对话列表、功能侧边栏）仍显示英文的问题。

## 原因

侧边栏是否加载简体中文，由 OpenAI 服务端的一个功能开关（Statsig layer `72216192.enable_i18n`）控制。
Codex 需要从 `chatgpt.com` 拉取这个开关；当前网络无法访问 `chatgpt.com`，所以开关默认关闭，界面语言设置
（`localeOverride = "zh-CN"`）对侧边栏不起作用。

## 原理

本工具用 Chromium 调试端口启动 Codex，然后在应用里注入一段补丁，把该开关强制设为“已启用”。
这样应用会加载自己内置的简体中文翻译，全程离线，不需要联网。

## 使用

1. 双击 `启动中文版Codex.bat`。
2. 选择 `1` 启动中文版 Codex。
3. 工具会先关闭正在运行的 Codex，再以中文模式重新打开并自动注入补丁。

注意：侧边栏中文只对“通过本工具启动的 Codex”生效。如果之后用开始菜单或任务栏的
原图标直接打开 Codex，侧边栏会回到英文。

## 不想每次手动启动？

在工具菜单中选择 `2`，会设置“开机自动启动”：每次登录 Windows 后自动以中文模式打开 Codex。

平时如果关闭了 Codex 再重新打开，请用 `启动中文版Codex.bat` 启动，或者给该 bat 创建
桌面/任务栏快捷方式替代原图标。

选择 `3` 可取消开机自动启动。

## 说明与限制

- 这是绕过官方服务端开关的本地补丁，只改运行中的页面状态，不修改 Codex 应用文件。
- Codex 官方更新后如果改了开关逻辑，此工具可能需要同步更新。
- 最彻底的官方方案仍是让 Codex 能访问 `chatgpt.com`（例如可用的代理/VPN），
  这样应用会自动加载服务端配置，无需每次通过本工具启动。
